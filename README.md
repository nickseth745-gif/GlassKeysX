# Glass Keys

An original liquid-glass style keyboard (IME) for Android.

Features: frosted translucent keys, dark/light mode, key magnifier bubble, shift + caps lock, auto-capitalize, word suggestions, numbers/symbols/emoji pages, haptics, hold-to-repeat delete, drag space bar to move the cursor.

## Build
Open in Android Studio, let Gradle sync, run on a device (Android 8.0+), then use the setup screen to enable and select the keyboard.
